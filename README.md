# Painel de Missões

Aplicação web de organização pessoal orientada por missões. A proposta é apoiar o ciclo de planejar, ser lembrado, iniciar, concluir, registrar e analisar o progresso.

## Status atual

Etapa 0A: fundação local com uma página inicial simples. Funcionalidades de produto e integrações ainda não foram implementadas.

## Stack

- Atual: Next.js, React, TypeScript, Tailwind CSS e ESLint.
- Planejada: Supabase (PostgreSQL, Auth e RLS), Vercel, PWA e Web Push.

## Execução local

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

Para validação, execute `npm run lint` e `npm run build`.

## Privacidade e documentação

Este repositório é planejado como público. Exemplos e documentação devem usar somente dados fictícios; dados pessoais e segredos não pertencem ao Git.

O segundo cérebro do projeto está em `docs/obsidian/`. Antes de uma implementação relevante, consulte [00 - Contexto Codex](docs/obsidian/00%20-%20Contexto%20Codex.md).
